┌─────────────────────────────────────────────────────────────────┐
│ 🛠️  TROUBLESHOOTING                                             │
└─────────────────────────────────────────────────────────────────┘

  Check if servers are running:
    netstat -ano | findstr "8888 8889"

  Kill Java processes:
    taskkill /F /IM java.exe

  Verify Java installation:
    java -version
    javac -version
